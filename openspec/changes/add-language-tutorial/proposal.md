## Why

Tisp 涵盖 32+ 章设计规范的丰富特性（ADT/GADT、效果系统、QTT、逻辑编程、进程演算、OOP、FRP 等），但缺乏**面向学习者的入门教程**。现有 `examples/` 中的 24 个示例分散且缺乏递进关系，`docs/spec.md` 是设计规范而非教学材料。新用户无从获悉语言的完整使用方式、特性间的协作方式及最佳实践。亟需一份**覆盖全部特性、编排合理、可验证运行的完整教程**，使学习者能够从零开始、逐步掌握 Tisp 的全部表达能力。

## What Changes

- 在 `tutorial/` 目录下创建**结构化完整教程**，按递进层次分章编排，覆盖 Tisp 全部语言特性
- 每章包含：概念讲解、语法入门、示范代码（可经 `--typecheck` / `--run` 验证）、练习题
- 覆盖全部 32 章节特性：基础语法 → 类型系统 → 效果系统 → 宏 → OOP → 逻辑编程 → 进程演算 → 验证 → 编程范式 → AOP 等
- 提供导航索引（`tutorial/INDEX.md`）与学习路线建议
- 所有示例代码须能通过 `--typecheck`（类型检查）且标注其适用标记（✅ 全可用 / ⚠️ 部分可用 / ⬜ 仅展示）

## Capabilities

无（纯文档变更，`skip_specs: true`）。不涉及语言行为变更、不新增或修改现有规范需求。

## Impact

- 新增 `tutorial/` 目录及约 20+ 章教程文件
- 可引用现有 `examples/` 中的示范程序，但不修改它们
- 不影响编译器、运行时、类型系统或其他代码
- 未来可能补充 `standard_doc/` 或 `docs/spec.md` 的交叉引用
